# Security Policy

## Supported Versions

Only the latest release is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities publicly.

Report them privately using GitHub Private Vulnerability Reporting or by email at `mopat@uni-muenster.de`.

Please include a description of the issue, affected versions, reproduction steps, and impact if known.

We will try to acknowledge reports within 7 days and coordinate a fix before public disclosure.

If you would like to be credited for the report, please let us know your preferred name or handle.
